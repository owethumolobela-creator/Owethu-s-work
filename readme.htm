👮‍♂️Police Case Management System - Stemsview Police Station

 

📌 Overview

 

Stemsview Police Station has been experiencing a significant rise in reported crimes including theft, fraud, and assault. The current paper-based system has proven inefficient, causing delays in retrieving case files and tracking investigations.

 

To resolve this, a digital Police Case Management Systemhas been developed. The system empowers officers to register, manage, and track cases efficiently using a graphical interface and a MySQL-backed database.

 

---

 

 ✅ Key Features

 

- 📝 Register, update, and delete Officer and Case records.

- 📖 View all case records to track progress and status.

- 🖥️ Java Swing GUI tailored for police use.

- 🔗 Database relationships ensure data integrity.

- ⚠️ Robust exception handling to prevent crashes or data loss.

🧩 Database Schema: `crime_management`

 

 1. OFFICER Table

 

| Field       | Data Type         | Constraints                  |

|-------------|-------------------|------------------------------|

| OfficerID   | INT               | PRIMARY KEY, AUTO_INCREMENT |

| FirstName   | VARCHAR(50)       | NOT NULL                     |

| LastName    | VARCHAR(50)       | NOT NULL                     |

| Rank        | VARCHAR(12)       | NOT NULL                     |

| Phone       | VARCHAR(15)       |                              |

 

---

 

2. CASE Table

 

| Field            | Data Type     | Constraints                          |

|------------------|---------------|--------------------------------------|

| CaseID           | INT           | PRIMARY KEY, AUTO_INCREMENT          |

| CaseDetails      | VARCHAR(255)  | NOT NULL                             |

| AttendingOfficer | VARCHAR(10)   | NOT NULL (FK to `OFFICER.OfficerID`) |

| Category         | VARCHAR(3)    | (FK to `CRIME_CATEGORY.CrimeTypeID`)|

| Location         | VARCHAR(50)   |                                      |

| ReportedOn       | DATE          |                                      |

| Status           | VARCHAR(1)    | (FK to `CASE_STATUS.StatusCode`)     |

 

---

 

3. CRIME_CATEGORY Table

 

| Field        | Data Type     |

|--------------|---------------|

| CrimeTypeID  | VARCHAR(12)   |

 

---

 

4. CASE_STATUS Table

 

| Field            | Data Type     | Description    |

|------------------|---------------|----------------|

| StatusCode       | INT           | e.g., 1 or 2    |

❓ FAQ

Q1: I'm getting a JDBC connection error?

Check if MySQL is running and verify your username/password in DBConnection.java.

 

Q2: The app crashes when I leave fields empty?

Input validation is required. Ensure all required fields (e.g., FirstName, LastName, CaseDetails) are filled.

 

Q3: Can I use another database like PostgreSQL?

The system is built specifically for MySQL. You would need to modify the SQL dialect and JDBC URL.
